=== РАСЧЕТ В ТИПЕ FLOAT ===
a_f = 100
b_f = 0.001

1) num1f = (a - b)^4 = 9.9996e+07
2) num2f = a^4 - 4a^3b + 6a^2b^2 = 9.9996e+07
   слагаемые: a^4 = 1e+08 | -4a^3b = 4000 | +6a^2b^2 = 0.06
3) denf = b^4 - 4ab^3 = -3.99999e-07
   слагаемые: b^4 = 1e-12 | -4ab^3 = 4e-07

4) num1f - num2f = 0
   должно быть b^4 = 1e-12
   но из-за вычитания двух чисел ~1e8 результат искажён
5) finf = diff_f / denf = -0
--> Результат с float: -0
